Политика конфиденциальности

Последнее обновление: 20 февраля 2026

1. Общие положения

Contact+ («Приложение») разработано как инструмент для синхронизации фотографий контактов между Telegram и адресной книгой iPhone. Мы уважаем вашу конфиденциальность и стремимся к максимальной прозрачности.

2. Какие данные обрабатываются

Приложение обрабатывает следующие данные исключительно на вашем устройстве:

  • Контакты — имена и номера телефонов из адресной книги iPhone для сопоставления с Telegram.
  • Данные Telegram — имена, номера телефонов и фотографии профилей ваших контактов в Telegram.
  • Telegram-сессия — данные авторизации для взаимодействия с API Telegram.

3. Как хранятся данные

  • Все данные хранятся локально на устройстве.
  • База данных Telegram зашифрована ключом, хранящимся в iOS Keychain.
  • Кэш сопоставлений защищён iOS Data Protection (Complete Protection).
  • Счётчик использования синхронизируется через iCloud Key-Value Store (только количество обновлённых фото).

4. Передача данных третьим лицам

Приложение не передаёт ваши данные третьим лицам. У нас нет серверов, аналитики, рекламных SDK или трекеров.

Приложение взаимодействует только с API Telegram (для авторизации, импорта контактов и загрузки фотографий) напрямую с вашего устройства.

5. Покупки

Приложение предлагает одноразовую покупку для безлимитного доступа через Apple In-App Purchase. Все транзакции обрабатываются Apple. Мы не имеем доступа к вашим платёжным данным.

6. Права пользователя

  • Вы можете отозвать доступ к контактам в настройках iOS в любой момент.
  • Вы можете выйти из Telegram-сессии в приложении — все локальные данные будут удалены.
  • Удаление приложения полностью удаляет все связанные данные с устройства.

7. Изменения

Мы можем обновлять эту политику. Актуальная версия всегда доступна на этой странице.
